## How do I use a promo code?

On the Checkout page (website and phone app) open the "Promo code and wallet" section, type the code and choose Apply. The discount and the new total appear straight away. Choose Remove to take it off. Codes that currently work for your store are shown as tap-to-apply chips. Only one promo code can be used per order, and it is not remembered: if you change your cart you may have to apply it again.

## What does a promo code take off?

A code gives either a percentage or a fixed rupee amount off the subtotal (the food), never the delivery fee, and never more than the subtotal. A percentage code can have a maximum discount. The discount is worked out again by the server when you place the order, so the final total is always the one checkout shows.

## Why does my promo code not work?

The message under the box says why. The code may not exist, be paused, have expired or not started, belong to a different store, need a bigger order ("Add items worth Rs X more"), have been fully used by everyone, have been used by you already, or be only for a first order.

## Can I use more than one promo code?

No. One promo code per order. You can combine one code with wallet credit.

## What is my wallet?

Open Wallet from the menu. It shows your credit balance, your referral code and a list of every credit and use. Credit comes only from referrals. You cannot add money, withdraw it or send it to someone else, and it does not expire. No card details are stored.

## How do I use wallet credit?

On Checkout tick "Use wallet credit". Credit is applied after any promo code and never goes beyond what is left to pay. If the order is cancelled or rejected (including when the payment fails) the credit you used is returned to your wallet.

## How does the referral programme work?

Share your referral code from the Wallet page. A friend can type it in the optional "Referral code" box when they sign up. When the friend's first order is delivered and its subtotal is Rs 100 or more, you and your friend each get Rs 50 in your wallets. You can earn up to 10 referral rewards. You cannot refer yourself.

## Is a promo code given back if my order is cancelled?

Yes. If an order is cancelled or rejected, the promo code redemption is released, so the code counts as unused again.

## Where do I see the discount on my order?

The order page and the delivered email show a "Discount" line (with the code) and a "Wallet credit" line when they apply, between the delivery fee and the total.

## How do I see my notifications?

Tap the bell (website) or open Notifications on the Account tab (phone app). Order updates, wallet credit and referral rewards appear there. In the notification settings you can switch order updates, wallet updates, promotions and push notifications on or off. Text-message and WhatsApp alerts are not available yet.
